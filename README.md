# 里山 DRIVE

タッチ操作を中心にした、日本の町を自由に走る WebGL 3D 運転ゲーム。

## 起動

Node.js はテスト時に使用します。ゲームの起動には Python 3 の静的サーバーだけで十分です。

```sh
npm start
# http://localhost:4173
npm test
```

`dist/` 内を任意の HTTPS 静的ホストに配置できます。Three.js は固定バージョンを同梱しています。初回の書体取得のみ Google Fonts を使用し、失敗時にはシステム書体へ切り替わります。

## 操作

- 「ドライブをはじめる」でクリープ走行から開始。停車状態で手動準備する場合は「Pから手動で発進する」を選ぶ。
- ブレーキを上へスライドしたまま D を選び、⒫ を押してパーキングブレーキを解除。
- ブレーキを離すとクリープ走行。アクセルは上へスライドするほど強く踏み込む。
- ハンドルの円周に沿って指を動かす。回転角は ±540°、ステアリング比は 15.9:1。タイヤの向きと車両旋回が連動する。
- 道路上を左右にスワイプして視点移動。「正面へ」で復帰。
- 地図の ↗ から住宅街、田舎道、高速道路、見晴らし峠、桜町駅前へ移動。すべて道路で接続されている。
- PC: W / ↑ アクセル、S / ↓ ブレーキ、A D / ← → ハンドル。Q / E ウインカー、C 車内・車外切替、Space パーキング、Esc 一時停止。
- ペダルを Tab で選択して ↑ / ↓ を押すと 10% 刻みで入力。フォーカスを離すと解除。

## 実装

- 描画: Three.js r180、スキャン由来の PBR 路面・壁・瓦・草地、HDRI の空・環境反射、太陽光、ソフトシャドウ、霧、手続き生成の地形・住宅・車両。モデルは実在メーカーの製品を複製しないオリジナル。車両は曲面ボディ、窓・ピラー、10本スポーク、ライト、ナンバー、内装と動的なメーターパネルを備える。
- 物理: 駆動・アイドルトルク・転がり/空気抵抗・エンジンブレーキ・重力・制動力の釣り合い。D/Rでも急坂では逆方向に転がり、Nでは重力だけで転がる。ブレーキには静止摩擦を含め、坂道での停止を維持する。60 Hz 固定刻みの自転車モデル、速度に応じた旋回応答、左右タイヤのアッカーマン角、車体のピッチ・ロール応答、AT シフトロック、クリープ、ブレーキ優先、駐車ブレーキ、5段のエンジン回転数モデル。
- 接触: 車両の向きを考慮した矩形分離軸判定、歩行者判定、建物の空間グリッド。接触時は停止するが、シフト・パーキング・ペダル・視点は変更しない。違反として白バイが追跡する。流血や身体損傷表現はない。
- 交通: 99台の左側通行車両が連続した周回経路を走る。相対速度と車間距離で追従し、高速道路では右側の前後の空間を確認してウインカー付きで追い越し、走行車線に復帰。開始画面では交通を進めず、発進時と交通経路のある出発地点への地図移動時には同方向の後続車を配置する。後続車の距離はミラーに表示し、遠方の車だけを使って後続交通を補充する。信号・歩行者への減速、歩行者、近接時に飛び出す子ども、停留所で停まる路面電車。
- 道路: 35本・約16.2kmの接続した道路。東の住宅地、南の周回路、農道、標高差約60mの峠道を追加。路面・白線・高度判定が同じ中心線を共有。カーブを曲線化し、交差点内の歩道を取り除き角を丸める。道路検索は40m単位の空間グリッドで絞り込む。
- 違反検出: 合図の方向・タイミング、低速の逆走、高速後退、黄色中央線、一時停止、車間距離、歩行者優先、接触、赤信号、速度超過、路外走行を検出。免許の持ち点を押すと条件・保留中の違反・取り締まり履歴を表示。検出の連発を防ぐクールダウン付き。
- ミラー: 同一の3Dシーンを3つの後方カメラで描画。低解像度 render target を交互に更新し、左右反転して合成。録画や背景画像ではない。
- 最適化: 共有 geometry/material、100m区画の InstancedMesh による建物・葉・道路標示の一括描画と区画カリング、車両メッシュの材質ごとの結合、遠方の車両と歩行者の描画距離制限、描画解像度上限、可変画質、別頻度での HUD/地図/ミラー更新、一定刻み物理、非表示時の一時停止。
- 自動画質は平均描画速度が落ちると影の解像度と画面の解像度を軽量化。メニューから高画質・軽量を固定できる。
- WebMCP 対応ブラウザでは読み取りと地図移動を公開。未対応ブラウザでもゲーム本体は動作する。

## 範囲と制約

現段階は、プレイ可能な手続き生成型シミュレーターです。写実的なスキャンモデルや実車メーカーの3Dアセット、実車検証済みのタイヤ・サスペンション物理ではありません。交通AI、信号、道路ネットワークはゲーム向けに簡略化しています。運転教習・法令判定用のシミュレーターではありません。実機の性能によって描画速度は異なります。

## 検証

`npm test` で AT シフト条件、平地/坂道のクリープ、急坂の逆方向への移動、Nの惰行、ブレーキ保持、エンジンブレーキ、操舵・接触判定、信号・スコア、道路接続・勾配・周回継ぎ目、追従・追い越し・危険な割り込みの回避を検証します。ブラウザでは車内/車外、地図移動、ミラー、スマホ縦横画面を確認しています。

Three.js のライセンスは `dist/vendor/THREE-LICENSE.txt` に同梱しています。

## v2 素材と品質

空・路面・コンクリート・漆喰・瓦・草地・葉の素材には [Poly Haven](https://polyhaven.com/license) の CC0 アセットを使用しています。出典とダウンロード元は `dist/assets/sources.json` に記録しています。色テクスチャは1K、法線は512pxへ最適化。実在の車種や特定の町を忠実に再現したデータではありません。

ブラウザ検証はローカルの WebGL 画面とスマホ相当の縦横ビューポートで実施しています。実機端末での性能測定ではありません。

## v3 走行・道路の変更

数値はゲーム向けの調整値で、特定の実車を測定したものではありません。ヒルスタートアシストや自動ブレーキ保持は付けず、坂道ではプレイヤーのブレーキ操作が必要です。追い越しは片側2車線の高速道路で行い、住宅街・峠道では対向車線を使った追い越しは行いません。一般道の交通AIは定義済みの周回経路を走ります。

## v4 後続交通・採点・駅前

- 桜町駅、駅前通り、商店街、中高層ビル・マンション、高架ホームと電車、住宅街の中の家を追加。建物は559棟、交通の周回経路は13本。駅前の歩道と広場にも歩行者を配置。
- 右左折は交差点30m手前、車線変更は3秒前の合図を基準に採点。一般道の逆走は2km/h超が1秒で50点減点。方向指示器は旋回後にハンドルが戻ると解除し、停車待ちだけでは時間切れにしない。
- 一時停止は停止線の手前4m以内で0.8秒の停止、車間距離は15km/h超で0.8秒分未満が1.5秒など、ゲーム用の許容値を設定。詳細は画面の採点表を参照。法令上の違反点数とは異なる。
- 合図の基準は[長野県警の案内](https://www.pref.nagano.lg.jp/police/anshin/koutsu/untenaizu.html)、横断者優先は[警察庁の案内](https://www.npa.go.jp/bureau/traffic/oudanhodou/info.html)を参照。
- 回帰テストは全出発地点の後続車、未合図・遅い合図、道路カーブの誤検知回避、一時停止、黄色線、車間・歩行者、移動後の判定リセットを含む40件。

## v5 6分の昼夜サイクル

- 24時間がプレイ時間360秒で一周。15:42から始まり、朝焼け・昼・夕焼け・夜へ滑らかに変化。描画速度とは独立した実経過時間で進め、開始画面・メニュー・非表示時には停止する。
- HDRの雲を共有する空シェーダー、太陽・月・星、移動する日差しと影、霧・環境反射・明るさを連動。ミラーも同じ空と照明を描画する。
- 暗くなると前照灯・尾灯・街灯・建物の窓が自動点灯。車の前照灯は影付きの1灯、街灯は最寄り4灯を使い回し、遠方の街灯と窓は発光材質で表現する。
- 360秒での一周、日付の折り返し、一時停止、低FPSでも進行速度が変わらないこと、明るさの連続性を含む43件のテスト。

## v6 追跡・救急車・運転席

- 衝突時の強制パーキングを撤去。操作入力と視点を維持して速度だけを止める。運転者の眼の位置を車体寸法に合わせ、横向き画面は水平画角82°を基準として窓越しの距離感を統一。
- 田舎の広い路側帯には1m幅を設け、白線と車体外縁のはみ出しを共通の道路形状から判定。通常走行時は路端との50cmの余裕も確認。交差点内と高速の路肩はこの判定から除外する。
- 違反の即時スコア減点を、白バイの追跡と取り締まりに置き換え。持ち点20点と架空の反則金を使用し、日本の法令上の点数制度や反則金額を再現するものではない。点数ゼロでもドライブは継続できる。
- 白バイは道路グラフで後方から追跡。高速の中央分離帯を横断せず、車の側方で同方向に1秒並ぶと取り締まりが成立。同種の違反は1件にまとめ、より重い速度超過は置き換える。追跡180秒で2台、300秒で3台。メニュー・非表示時は停止し、追跡中の地図移動は不可。
- 救急車は走行開始18秒後から近くの交通経路に登場。赤色灯、サイレン、接近距離を表示。周囲の車は車道左へ寄せて減速。告知から6秒の猶予後、45m以内で2.5秒進路を塞ぐと違反。左への十分な間隔、10km/h未満への減速、交差点外への退避を判定する。
- 二輪・乗員・救急車の専用モデル。白バイ3台と救急車1台を使い回し、材質ごとにメッシュを結合。サイレンは音声ON時のみ再生。
- 道路接続、追跡成立条件、増援の境界時刻、重複請求防止、路端距離、救急車妨害と進路譲りの回帰テストを追加。

## v7 運転UIの刷新

- グラファイト・白・アンバーの配色に統一。速度・シフトを中央のメーターパネルにまとめ、補助操作と地図は画面の端へ配置。
- ハンドルとペダルの質感、操作アイコン、文字サイズ、開始画面、地図・免許履歴・一時停止メニューを刷新。ペダルの踏み込み量を色と数値で表示。
- スマホ縦横に専用の配置を用意。開始前は運転操作とサイドミラーを隠し、開始後は同じ3Dシーンのミラーを表示。

## v8 衝突・警察の会話・飛行とミサイル

- 接触時に車体の重なりを分離し、障害物へ向かう速度だけを止める。D/R・ハンドル・カメラは維持し、バックや切り返しで離脱できる。衝突音、火花、短い揺れ、画面端のフラッシュと接触相手の表示を追加。
- 白バイが側方で取り締まると運転を一時停止し、警察の呼びかけ、違反内容・持ち点・反則金の確認、運転再開を表示。音声ON時は対応ブラウザの日本語読み上げも使用。料金処理は会話開始時に1回だけ行う。
- 「飛行」（F）で離陸。↑上昇／↓下降を押し続ける（PC: Z / X）と高度変更。ハンドル・アクセル・ブレーキで空中移動。「着陸」を押すと空いている道路へ着陸し、着陸中に障害物が入るとホバリングへ戻る。
- 「ミサイル」（M）で中央照準の方向へ発射。車や建物に命中すると爆発・煙・破片・瓦礫が発生し、破壊対象の描画と接触判定を除去する。1.1秒の再装填、最大6発・飛翔時間4.5秒。破壊すると器物破壊として白バイが追跡。破壊状態はそのプレイ中のみで、ページ再読み込みで復元。
- 建物の破壊は棟単位の簡略表現で、構造破壊シミュレーションではない。歩行者へのミサイル命中・身体損傷表現は含めない。飛行もゲーム向けのホバリングモデル。
- 音は開始ボタンで有効になり、右上のサウンドボタンで消音。日本語音声の利用可否・声質は端末による。粒子360個・破片100個・瓦礫240個・ミサイル6個の固定プールを使い、建物の分割バッチは維持する。
- 接触後の後退・旋回、斜めの接触、飛行・安全な着陸、ミサイルの高速通過対策・寿命、上昇とペダルの同時タッチを含む69件の自動テスト。

## v9 飛行機の操縦とミサイル演出

- 飛行を固定翼のゲームモデルに変更。推力で滑走し、前進速度・迎角に応じた揚力で離陸。機首上げで上昇・減速、機首下げで下降・加速し、左右のバンクで旋回する。低速・過大な迎角では失速し、揚力が落ちて機首と高度が下がる。空中での静止・垂直ホバリング・後退は廃止。
- 左の操縦桿を下へ引くと機首上げ、上へ押すと機首下げ、左右でバンク。右の推力レバーは指を離しても設定を維持。ブレーキは飛行中にエアブレーキとなる。PCでは A/D または左右キーでバンク、下/Z で機首上げ、上/X で機首下げ、W/S で推力調整、Q/E でラダー、Space でエアブレーキ。
- 姿勢計・対気速度・高度・昇降速度・推力・失速警告を表示。翼と尾翼、後部エンジン、動く補助翼を追加し、車内視点も機首とバンクに連動。飛行中の車外カメラは前方を見る。
- 道路上の「着陸補助」は前進しながら降下・フレアする。操縦入力や障害物で補助を解除し、着陸経路が塞がれたら推力を上げる。手動着陸も可能。強い降下や大きな傾きでの接地はハードランディングとして扱う。
- ミサイルに二重の噴射炎と太い煙の尾、着弾に火球・火花・拡大する衝撃波・舞い上がる爆煙・跳ねる破片・閃光を追加。音と揺れは距離で減衰。発射口とカメラの位置差を補正して照準へ向ける。
- 炎360・煙440・破片120・衝撃波5の固定プールで再利用。爆発のたびに描画オブジェクトを増やさず、動いているエフェクトだけを更新。点描の大きさはカメラの画角と解像度に合わせる。
- 飛行は操縦の感覚を優先した簡略モデルで、実機の飛行特性を検証したものではない。75件の自動テストには揚力・推力・旋回・失速・着陸・同時タッチ・推力保持・エフェクトの寿命とプール再利用を含む。


## v10 海・川・山・モールへ拡張

- 道路35本、約16.2km、交通99台・16周回経路。片側2車線の海岸通り、桜川を渡る橋、3車線の一方通行モール外周、標高126mの雲見峠、マリーナへの道を既存の街に接続。
- 一般道でも安全な車線変更・追い越しを行い、一方通行のNPCと白バイの道路グラフは合法な方向のみを使用。全ての一方通行車線を正しく走れる一方で、逆走と未合図・遅い合図を検出。幅の異なる接続道路に近づいてもNPCが横へ飛ばないよう周回路の車線寸法を維持する。
- 水面、海岸の低い地形、川と河口は同じ水域関数を共有。マリーナの停車位置で「船」に切り替え、推進・減速・惰性・舵・後進・投錨を操作。岸と桟橋への進入を防ぎ、桟橋付近に戻って停車すると車へ復帰。海から南側の河口を通って川へ入れる。
- 桜テラスはガラスの店舗ファサード、庇、広場を持つモール。併設駐車場は1F・2F・3F・屋上の4層と勾配5.7%の連続スロープ、区画、柱、外周壁、駐車車両、階別表示。車輪の現在の高さを使い階の飛び移りを防ぐ。スロープで上下でき、場内は10km/h。店舗内部を徒歩で探索する機能はない。
- 山道・田舎道に桜並木、花畑、針葉樹、ガードレール、薄霧と夜の蛍。花は1枚の共有アトラスを使うインスタンス、蛍は固定220点、水面は共有シェーダーで描画。照明は既存の4灯プールを高さも含めて選び、駐車場の階にも対応。
- 地図にマリーナ・雲見峠・桜テラス・立体駐車場・海岸通りの出発地点を追加。船の操船、道路方向、車線変更、河岸と桟橋、橋の高さ、上下の駐車場スロープ、停止車両を追い越すNPCを含む90件の自動テスト。スマホ相当の390×844・844×390表示で確認。

## v11 — 同じ車で、陸・水・空へ

- 水上モードは別の船への乗り換えを廃止。同じ車の浮体・推進器を展開し、水面で車輪を格納する。位置・向き・シフトは維持され、岸に上がって停車すると車に戻せる。マリーナに接続道路と進水スロープを追加。
- ミサイルは車体中央のランチャーから車体正面へ直進。カメラの左右スワイプとは独立し、照準が実際の発射方向を投影する。下降する笛音と噴射音を合成。
- 運転席を前後 ±24 cm、高さ −12〜+16 cm で調節。運転席モデルとカメラが連動し、端末の座席設定のみ localStorage に保存する。
- 車両モードパネル、独立した発射ボタンと装填表示、徒歩スティック・走行ボタンを追加。徒歩は WASD、Shift で走る、V で乗り降り。停車・安全なドア位置・同じ階の車への接近を検査し、駐車車両は交通の障害物として残る。
- 道路外では警官が白バイをその場に停めて降車し、建物を避けながら追う。徒歩で追いつくと既存の取り締まり会話に移行し、その後は白バイまで戻る。
- 追跡中に空中へ逃げると戦闘機1機が出動し、回避可能な誘導ミサイルを発射。全機撃墜の60秒後に2機、次は3機、以降も60秒後に3機。ゲームを一時停止するとタイマーも停止。航空機は最大3機、敵ミサイルは最大6発。3発被弾で推力を失い緊急降下し、道路への復帰・修復が可能。
- 新しいシミュレーションは純粋なモジュールに分離。警官の局所経路判断は約6 Hz、物理は既存の固定ステップ、描画は固定数のモデルを再利用。

検証：車体中央の射出軸、座席の上限、乗降・歩行衝突、駐車車両、警官の降車と再乗車、戦闘機の出動・60秒増援・遮蔽物・被弾・墜落、水上変形と岸への復帰、既存のAT・交通・道路を自動テスト。スマホ縦横のローカルプレビューで座席変更、徒歩、同じ車の水上航行、ミサイル、飛行画面を確認。

### v12 — 破壊・徒歩装備・警察の応答

- 物体の材質別の衝突エネルギーと押し込み量で破壊。低速でぶつかっても後退でき、十分な力を加えると突破できます。高速道路・山道・橋の柵は短いパーツ単位で表示と衝突を同時に解除します。
- 静的景観は24 mの空間インデックスでミサイル周辺だけを検索。建物、標識、樹木、路面、駐車場床、桟橋などを既存インスタンスやインデックスバッファのまま破壊します。地形・海水面は維持します。NPC、警官、白バイ、路面電車、救急車、降車後の自車も対象です。
- 徒歩のジャンプ（Space／タッチ）と視線方向のロケット（M／発射ボタン）。天井・着地・空中の移動を扱い、二段ジャンプと空中での乗車を防ぎます。
- 通常の取り締まりは車速の絶対値が5 km/h以下。3回のノック → 警察側への視線移動 → 会話。徒歩では従来の接近判定です。
- 持ち点0で免許停止、以後の運転で無免許運転を記録。移動・修復では持ち点は回復しません。ロケットによる破壊、警察への攻撃、30秒以内の3回の破壊で武装警戒。警察の銃撃、遮蔽物、体力／車体の損傷、制圧と再開を追加。処分・持ち点はゲーム独自の設定です。
- 戦闘機は前方を周回して攻撃し、速度に応じて先行距離を調整。マップに機首方向と、範囲外の機体の方向・距離を表示します。
- 市街地の街灯を増設し、夜の窓・月明かり・環境光を調整。実光源は近傍6灯に固定し、壊した照明は消えます。

検証: `npm test`（v12追加を含む120件）。デスクトップで徒歩ジャンプ、ロケットと破壊、警察銃撃、夜景、低速捕捉から会話までの動作を確認。

### v13 — 核弾・緩い誘導・視界に応じた発砲

- 発射ボタン上の通常弾／核弾切替。核ミサイルは着弾点から半径100mの球形範囲を破壊し、12秒で再装填。大型の煙・火球・100mへ広がる衝撃波を固定エフェクトプールで描画。4.5秒で届かなかった核弾は空中で爆発します。
- 自弾は発射時に正面25度・420m以内の戦闘機を捕捉し、旋回速度を0.38 rad/sに制限して緩く追従。背後へ回り込んだ機体・破壊済み機体は追いません。
- 既に出動して警戒中の航空隊は、プレイヤーの周囲80mに生存する歩行者・建物がなければ地上へも攻撃。人や建物の近くへ移動すると地上攻撃中の誘導弾も解除。地上だけの通常追跡では新たな航空隊は出動しません。
- 警官は実際のカメラの視野と遮蔽物を確認し、画面内で0.6秒以上連続して見えてから発砲。画面外へ出た間は新たに撃ちません。

検証: `npm test` 126件通過。v13の実画面確認・公開はネットワーク権限の制限で未実施（localhostのbindとソース同期のDNS解決が拒否されたため）。
