# 里山 DRIVE

タッチ操作を中心にした、日本の町を自由に走る WebGL 3D 運転ゲーム。

## 起動

Node.js はテスト時に使用します。ゲームの起動には Python 3 の静的サーバーだけで十分です。

```sh
npm start
# http://localhost:4173
npm test
```

`dist/` 内を任意の HTTPS 静的ホストに配置できます。Three.js は固定バージョンを同梱しています。初回の書体取得のみ Google Fonts を使用し、失敗時にはシステム書体へ切り替わります。

## 操作

- 「ドライブをはじめる」を押す。
- ブレーキを上へスライドしたまま D を選び、⒫ を押してパーキングブレーキを解除。
- ブレーキを離すとクリープ走行。アクセルは上へスライドするほど強く踏み込む。
- ハンドルの円周に沿って指を動かす。回転角は ±540°、ステアリング比は 15.9:1。タイヤの向きと車両旋回が連動する。
- 道路上を左右にスワイプして視点移動。「正面へ」で復帰。
- 地図の ↗ から住宅街、田舎道、高速道路へ移動。すべて道路で接続されている。
- PC: W / ↑ アクセル、S / ↓ ブレーキ、A D / ← → ハンドル。Q / E ウインカー、C 車内・車外切替、Space パーキング、Esc 一時停止。
- ペダルを Tab で選択して ↑ / ↓ を押すと 10% 刻みで入力。フォーカスを離すと解除。

## 実装

- 描画: Three.js r180、PBR 素材、太陽光、ソフトシャドウ、霧、手続き生成の地形・住宅・車両。モデルは実在メーカーの製品を複製しないオリジナル。
- 物理: 60 Hz 固定刻みの自転車モデル、速度に応じた旋回応答、AT シフトロック、クリープ、ブレーキ優先、駐車ブレーキ、5段のエンジン回転数モデル。
- 接触: 車両の向きを考慮した矩形分離軸判定、歩行者判定、建物の空間グリッド。事故時は停止しスコアを減点する。流血や身体損傷表現はない。
- 交通: 左側通行の自動車、先行車・信号・歩行者への減速、歩行者、近接時に飛び出す子ども、停留所で停まる路面電車。
- スコア: 接触、赤信号、継続的な速度超過、対向車線・路外走行。検出の連発を防ぐクールダウン付き。
- ミラー: 同一の3Dシーンを3つの後方カメラで描画。低解像度 render target を交互に更新し、左右反転して合成。録画や背景画像ではない。
- 最適化: 共有 geometry/material、InstancedMesh による建物・植生・道路標示の一括描画、描画解像度上限、可変画質、別頻度での HUD/地図/ミラー更新、一定刻み物理、非表示時の一時停止。
- 自動画質は平均描画速度が落ちると影と解像度を軽量化。メニューから高画質・軽量を固定できる。
- WebMCP 対応ブラウザでは読み取りと地図移動を公開。未対応ブラウザでもゲーム本体は動作する。

## 範囲と制約

現段階は、プレイ可能な手続き生成型シミュレーターです。写実的なスキャンモデルや実車メーカーの3Dアセット、実車検証済みのタイヤ・サスペンション物理ではありません。交通AI、信号、道路ネットワークはゲーム向けに簡略化しています。運転教習・法令判定用のシミュレーターではありません。実機の性能によって描画速度は異なります。

## 検証

`npm test` で AT シフト条件、クリープ、前進/後退、制動、操舵方向、時間刻み、接触判定、信号違反、継続違反・スコア下限を検証します。ブラウザでは車内/車外、地図移動、ミラー、スマホ縦横画面を確認しています。
